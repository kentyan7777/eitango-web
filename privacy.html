プライバシーポリシー

本プライバシーポリシーは、KENICHI KAWAGUCHI（以下「当方」といいます）が提供するiOS向けアプリケーション「Eitango」（以下「本アプリ」といいます）における、ユーザーの個人情報およびデータの取り扱いについて定めるものです。

1. 収集する情報と利用目的

本アプリはユーザーのプライバシーを尊重し、個人を特定できる情報（氏名、住所、電話番号、メールアドレスなど）を、当方が直接収集・保存・販売することはありません。

本アプリ内で入力・生成されたデータは、以下の目的で利用されます。

  • 単語帳データと学習履歴: ユーザーが登録した英単語、意味、メモ、および学習の進捗（スプリント記録など）等は、すべてユーザーの端末内（ローカルストレージ）にのみ保存されます。当方のサーバーにこれらのデータが送信・収集されることはありません。
  • AI機能（文章生成・音声生成）の利用: 本アプリは、単語の詳細（語源、例文、ニュアンス）や音声データ等を動的に生成するため、ユーザーが検索または登録した「単語」のテキストデータを、当方が管理する中継サーバー（プロキシ）を経由して Google の提供する API（Gemini API およびGoogle Cloud Text-to-Speech API）に送信します。この送信データはAIによるテキスト・音声生成の目的にのみ使用され、当方が特定のユーザーを識別するデータとして監視・蓄積することはありません。

2. サードパーティサービスについて

本アプリでは、一部の機能を提供するために以下のサードパーティのAPIを利用しています。これらのサービスにおけるデータの取り扱いについては、各社のプライバシーポリシーに従います。

  • Gemini API / Google Cloud Text-to-Speech API データの利用目的：単語情報の生成、および音声データの生成
    プライバシーポリシー: https://policies.google.com/privacy
  • Apple (StoreKit) データの利用目的：アプリ内課金（Eitango Pro等のサブスクリプション）の決済処理
    （※決済処理はすべてAppleが提供するシステムで行われ、当方がユーザーのクレジットカード情報等を直接取得することはありません）

3. データのバックアップとエクスポート

本アプリは、ユーザー自身がアプリ内のデータをJSON形式でファイルとしてエクスポート（バックアップ）する機能を提供しています。エクスポートされたファイルの管理・保管はユーザー自身の責任で行われるものとし、エクスポート後のデータの紛失や漏洩について、当方は一切の責任を負いません。

4. 利用状況の解析について

本アプリは、アプリのクラッシュ情報や機能の利用状況を匿名化された状態で収集するため、Appleが提供する標準のオプトイン型アナリティクス（App Store Connect）を利用する場合があります。これらはアプリの品質向上およびバグ修正の目的でのみ使用されます。

5. 免責事項

本アプリが生成するAIによる解説や例文の正確性・妥当性について、当方は保証するものではありません。本アプリを利用したことによって生じたトラブルや損害について、当方は一切の責任を負わないものとします。

6. プライバシーポリシーの変更

当方は、法令の変更や本アプリの機能追加・変更に伴い、事前の予告なく本プライバシーポリシーを改定する場合があります。

変更後のプライバシーポリシーは、本ページ（またはアプリ内のリンク先）に掲載された時点から効力を生じるものとします。
